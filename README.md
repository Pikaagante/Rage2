# Rage

Rage est un jeu 2D inspiré de jeux comme Unfair Mario ou Cat Mario, dans lequel le joueur doit réussir une cinquantaine de niveaux, chacun proposant des défis et des difficultés différentes.

Le jeu se déroule dans un environnement mêlant labyrinthe et énigmes. Pour progresser, le joueur devra faire preuve d'observation et de réflexion, notamment en modifiant certains fichiers du jeu, en déchiffrant des symboles et en résolvant différentes énigmes afin de débloquer la suite de l'aventure.
